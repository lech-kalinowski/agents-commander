# Talks

Conference decks, speaker notes, and promotional material are maintained
separately from product implementation and user documentation. They are not
runtime dependencies and are excluded from npm packages.

The Code Europe material is being migrated in a separate pull request. The
[previous deck and runbook](https://github.com/lech-kalinowski/agents-commander/tree/codex/review-and-release-0.1.5/presentation)
remain available on the preserved integration branch. That historical snapshot
may describe older source or licensing; use the current [README](../README.md)
and [LICENSE](../LICENSE) for the product.

For reusable workflows, see [Examples](../Example/README.md). Changes to demos
that ship with Commander belong in product PRs; changes specific to a talk
belong in a separate documentation PR.
