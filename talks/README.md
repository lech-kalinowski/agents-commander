# Talks

Conference decks, speaker notes, and promotional material are maintained
separately from product implementation and user documentation. They are not
runtime dependencies and are excluded from npm packages.

## Code Europe 2026

- [Speaker runbook](code-europe-2026/README.md): 40–50 minutes including Q&A.
- [PowerPoint deck](code-europe-2026/Agents_Commander_Protocol.pptx): architecture,
  protocol, live-demo cues, and model-adapter roadmap.

Use the current [README](../README.md) and [LICENSE](../LICENSE) for product
setup and licensing. Historical integration commits remain available in git;
the directory above contains the maintained conference material.

For reusable workflows, see [Examples](../Example/README.md). Changes to demos
that ship with Commander belong in product PRs; changes specific to a talk
belong in a separate documentation PR.
