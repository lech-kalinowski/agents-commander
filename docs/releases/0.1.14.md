# 0.1.14 release acceptance

Prepared November 10, 2026. All final-artifact validation gates passed. Registry
publication and the local upgrade are still pending; a source push alone is not
an npm release. This record is excluded from the npm archive, allowing evidence
to be updated without changing the tested package.

## Scope

- Plain interactive shells with Ctrl+T from files or F2/S, without AI routing,
  automatic restart or capture. Session replacement requires confirmation.
- Antigravity CLI (`agy`) as the `antigravity` adapter, including configuration,
  exact addressing, templates and consented capture/export.
- Gemini CLI deprecated and retained for explicit legacy compatibility. Saved
  Gemini commands and custom targets are not silently changed.
- Existing 0.1.13 communication, rendering and protocol protections remain.

## Observed validation

- Full `npm run verify`: passed. Typecheck; 1,904 TypeScript tests passed,
  two skipped across 127 files; 28 Python tests; development watch; build;
  built CLI isolation; packed installation, startup and 121 templates.
- Packed TUI: 100 panels, stable IDs, resize/fullscreen, both themes and twenty
  synthetic agent PTYs. Real plain-shell launch through Ctrl+T and F2/S,
  directory selection, protocol rejection and exit without automatic restart.
- Real Antigravity/Codex against the sealed installation: six routed deliveries,
  repeat delivery, QUERY and STATUS passed without rescue Enter/retry. Both
  sessions stopped. Antigravity used plan/sandbox mode; Codex was read-only.
- Real Claude/Codex against the same installation, independently in side-by-side
  and stacked layouts: short, rally2, rally3, reply-chain, multiline, QUERY,
  STATUS and BROADCAST passed. Each run delivered fifteen messages, including
  a continuing reply chain and a 32-line payload, with automatic submission and
  cleanup. Live runs observed scroll-margin changes, not REP; REP remains
  covered by deterministic tests, not claimed as live evidence here.
- Sixteen real OpenCode/APEX sessions: baseline, stress, correction and whole-run
  gates passed; exactly 22 accepted commands and 72 delivered routes. All sixteen
  startup fullscreen checks passed, including hidden-recipient broadcast and
  resize coverage. One deliberate malformed frame generated exactly one fixed
  correction notice; the same model/session corrected with a fresh sequence,
  received its ACK, and delivered once without rescue input or resize.
- APEX natural quit and complete owned-process cleanup passed. All tools were
  denied; global configuration was unchanged; no raw output was printed or
  recorded. No incidental recovery or unaccounted correction feedback occurred.
- OpenCode's documented single-space paste normalization was observed for some
  payloads: wire bodies were exact and the existing narrowly scoped receiver
  check passed. This is not a claim that all stored receiver bodies were byte
  identical. No acceptance condition was weakened for this release.
